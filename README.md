# Mahmudul Hasan — Portfolio

Personal portfolio and service website for [Mahmudul Hasan](https://mahmudulhasan.site), a Performance Marketing & Growth Specialist. Built with Next.js 14, React 18, and Tailwind CSS 4.

## Services Featured

- GoHighLevel & CRM Setup
- AI Automation & Chatbots
- Funnels & Landing Pages
- Facebook Ads & Lead Gen
- Shopify & WordPress Development
- Project Management & SOPs

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the site.

## Deploy

This project deploys to [Vercel](https://vercel.com). Production builds are verified with:

```bash
npm run build
```
